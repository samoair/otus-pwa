# Triage Labels

The following label names are used to manage the triage workflow:

- `needs-triage` — maintainer needs to evaluate
- `needs-info` — waiting on reporter
- `ready-for-agent` — fully specified, AFK-ready (an agent can pick it up with no human context)
- `ready-for-human` — needs human implementation
- `wontfix` — will not be actioned

These are the default label names used by the `triage` and `to-issues` skills.

If your issue tracker uses different labels, update this file and ensure your workflow matches.
