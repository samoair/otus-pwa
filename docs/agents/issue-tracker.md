# Issue Tracker: Local Markdown

This repository uses local Markdown files for issue tracking. Issues are stored as `.md` files under `.scratch/<feature>/`.

## How it works

- Each feature or bug is represented by a Markdown file.
- Files are named with a descriptive slug, e.g., `add-dark-mode.md`.
- The `.scratch/` directory is git-ignored to avoid cluttering the repo history.
- Skills like `to-issues` and `triage` read from and write to this directory.

## Creating a new issue

Run:

```bash
npx qwen to-issues "Add dark mode toggle"
```

This will create `.scratch/add-dark-mode.md` with a template.

## Viewing issues

List all issues:

```bash
ls .scratch/
```

Open an issue in your editor:

```bash
code .scratch/add-dark-mode.md
```

## Caveats

- This approach is ideal for solo developers or small teams.
- For team collaboration, consider switching to GitHub or GitLab later.
- Ensure `.scratch/` is in `.gitignore`.
