## Writing CONTEXT.md

Start with:

```markdown
# Context

## Domain Terms
- **Product**: A catalog item available for purchase.
- **Cart**: A user’s collection of selected products.
- **Order**: A confirmed purchase with payment.

## Key Workflows
1. User adds product to cart → cart updates
2. User checks out → order is created
3. Order is fulfilled → inventory updated

## Constraints
- Payment must be processed within 5 minutes of checkout.
- Cart persistence requires user authentication.
```
